Lanzador del Radar

Envía pedidos a la rutina de Claude que mantiene tu Radar de Licitaciones. La primera vez claude.ai te pide permiso para usar el conector «Claude Code Remote».

Buscar precios de mercado

Claude busca en tiendas chilenas cada ítem de las licitaciones elegidas (máximo 5), guarda el presupuesto en el repositorio y GitHub verifica cada precio en la página de la tienda. Tarda entre 10 y 30 minutos.

Actualizar ahora

Corre el radar y las órdenes de compra en GitHub y rehace los presupuestos (30 a 80 minutos). Ocurre sola de lunes a viernes a las 8:50.

Al terminar, la rutina te avisa en el teléfono. Para ver los datos nuevos en el dashboard aprueba la subida en la sesión «Rutina: Actualizar Radar de Licitaciones» de la app de Claude. Si el envío no funciona, pídelo en el chat («busca precios de 3890-217-E226») o corre los workflows en GitHub Actions.
